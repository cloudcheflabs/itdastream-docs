<h2 align="center" style="margin-top: 1.5rem;">Kafka-Compatible Streaming on S3, with Exactly-Once Streaming to Iceberg</h2>

<p align="center" style="font-size: 1.1rem; max-width: 720px; margin: 1.5rem auto; color: #555;">
  ItdaStream speaks the Apache Kafka protocol but disaggregates compute from storage with an
  S3 backend — unlimited retention at a fraction of the cost, stateless brokers that scale
  without data reshuffling. A built-in, Flink-style streaming engine runs on the brokers
  themselves: send JSON or Avro to a topic and it lands in an Apache Iceberg table with
  exactly-once semantics — no separate stream-processing cluster to operate.
</p>
